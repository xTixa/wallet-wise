# WalletWise

Uma aplicação web moderna para gestão financeira pessoal, com dashboards interativos, análises inteligentes e objetivos de poupança.

---

## 🇵🇹 

**WalletWise** é uma plataforma web criada para ajudar os utilizadores a acompanhar e melhorar a sua saúde financeira.  
Enquanto muitas aplicações se limitam ao simples registo de receitas e despesas, o WalletWise destaca‑se ao oferecer:

- **Dashboards interativos** para visualizar hábitos financeiros
- **Estatísticas inteligentes** que identificam padrões e gastos excessivos
- **Objetivos de poupança** com acompanhamento visual
- **Sugestões personalizadas** para melhorar a gestão do orçamento
- **Interface moderna, intuitiva e responsiva**

O objetivo é transformar dados financeiros em **informação útil**, promovendo decisões mais conscientes e hábitos sustentáveis.

---

## 🇬🇧 

**WalletWise** is a modern web platform designed to help users track and improve their financial well‑being.  
While many apps only store income and expense records, WalletWise goes further by providing:

- **Interactive dashboards** to visualize financial habits
- **Smart analytics** that detect patterns and overspending
- **Saving goals** with visual progress tracking
- **Personalized suggestions** to improve budgeting
- **A modern, intuitive and responsive interface**

The platform aims to turn financial data into **actionable insights**, empowering users to make informed decisions and build healthier financial habits.
